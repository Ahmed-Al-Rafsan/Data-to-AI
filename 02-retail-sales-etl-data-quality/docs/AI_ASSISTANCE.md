# Authorship and AI assistance

This project was developed as a beginner learning exercise by **Ahmed Al Rafsan**. The author chose the dataset-handling decisions, implemented the steps in VS Code/Jupyter, investigated errors, and explained the reasoning behind preserving unknown quantities and discounts.

AI assistance was used for **teaching pandas syntax, code review, logging/error-handling explanations, and documentation/packaging guidance**. The code published in this repository was reconstructed from code snippets supplied during the learning conversation because the original binary `.ipynb` file was not transferred. The portable repository version keeps one main notebook and the author's beginner-first processing approach, while making only the adjustments required to run with the bundled CSV and catch missing source files at extraction.

This is not presented as unsupervised professional production experience, a deployed cloud system, or a large-scale automation platform.
